# @turystack/frontend-config

Shared biome + TypeScript config for turystack web and mobile apps.

## Installation

```bash
pnpm add -D @turystack/frontend-config
```

## Presets

```json
{
  "extends": ["@turystack/frontend-config/biome"]
}
```

Available: `@turystack/frontend-config/biome`, `@turystack/frontend-config/tsconfig.web`, `@turystack/frontend-config/tsconfig.mobile`
